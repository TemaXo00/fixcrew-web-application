## Quick Start

```bash
# Cloning repository
git clone https://github.com/TemaXo00/fixcrew-web-application.git
# Move into directory
cd fixcrew-web-application
# Copy enviroment variables example
cp .env.example .env
# Run all containers
docker compose up --build
```
