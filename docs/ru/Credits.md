# Использованные технологии

## Frontend

- [Vue 3](https://github.com/vuejs/core) - Фреймворк для написания клиентских приложений
- [Vite](https://github.com/vitejs/vite) - Сборщик и инструмент разработки
- [Pinia](https://github.com/vuejs/pinia) - Управление состоянием (store)
- [Vue Router](https://github.com/vuejs/router) - Маршрутизация
- [TailwindCSS](https://github.com/tailwindlabs/tailwindcss) - CSS-фреймворк (утилитарный)
- [@tailwindcss/vite](https://github.com/tailwindlabs/tailwindcss) - Интеграция Tailwind с Vite
- [Axios](https://github.com/axios/axios) - HTTP-клиент
- [Leaflet](https://github.com/Leaflet/Leaflet) - Библиотека для интерактивных карт
- [Mapbox GL](https://github.com/mapbox/mapbox-gl-js) - Картографический движок
- [@toast-ui/calendar](https://github.com/nhn/tui.calendar) - Календарь для админ-панели
- [Vee-Validate](https://github.com/logaretm/vee-validate) - Валидация форм
- [Yup](https://github.com/jquense/yup) - Схемная валидация объектов
- [@vee-validate/yup](https://github.com/logaretm/vee-validate) - Интеграция Yup с Vee-Validate
- [@heroicons/vue](https://github.com/tailwindlabs/heroicons) - Иконки для Vue
- [marked](https://github.com/markedjs/marked) - Парсер Markdown
- [@hackingzhang/vue-marked](https://github.com/mikedamay/vue-marked) - Vue-компонент для Markdown
- [Vue Test Utils](https://github.com/vuejs/test-utils) - Утилиты для тестирования Vue-компонентов
- [Vitest](https://github.com/vitest-dev/vitest) - Фреймворк для unit-тестирования
- [jsdom](https://github.com/jsdom/jsdom) - DOM-эмуляция для тестов
- [ESLint](https://github.com/eslint/eslint) - Линтер кода
- [@antfu/eslint-config](https://github.com/antfu/eslint-config) - Конфигурация ESLint от Antfu
- [eslint-plugin-vue](https://github.com/vuejs/eslint-plugin-vue) - ESLint-правила для Vue
- [Prettier](https://github.com/prettier/prettier) - Форматтер кода
- [Oxlint](https://github.com/oxc-project/oxc) - Быстрый линтер на Rust
- [TypeScript](https://github.com/microsoft/TypeScript) - Статическая типизация
- [vue-tsc](https://github.com/vuejs/language-tools) - TypeScript-проверка Vue-компонентов
- [npm-run-all2](https://github.com/mysticatea/npm-run-all) - Запуск нескольких npm-скриптов
- [vite-plugin-vue-devtools](https://github.com/vuejs/devtools-next) - Инструменты отладки Vue

## Backend

- [NestJS](https://github.com/nestjs/nest) - Фреймворк для написания серверной архитектуры
- [Prisma](https://github.com/prisma/prisma) - ORM для работы с базой данных
- [RabbitMQ](https://github.com/rabbitmq/rabbitmq-server) - Брокер сообщений для микросервисной коммуникации (AMQP)
- [Redis](https://github.com/redis/redis) - In-memory хранилище для кэширования и брокер очередей
- [PostgreSQL](https://github.com/postgres/postgres) - Реляционная база данных
- [MinIO](https://github.com/minio/minio) - S3-совместимое объектное хранилище для файлов
- [BullMQ](https://github.com/taskforcesh/bullmq) - Библиотека очередей на основе Redis
- [Bull](https://github.com/OptimalBits/bull) - Очереди на основе Redis
- [@nestjs/bull](https://github.com/nestjs/bull) - Интеграция Bull с NestJS
- [@nestjs/bullmq](https://github.com/nestjs/bull) - Интеграция BullMQ с NestJS
- [ioredis](https://github.com/luin/ioredis) - Redis-клиент для Node.js
- [AMQP connection manager](https://github.com/benbria/amqp-connection-manager) - Менеджер соединений для RabbitMQ
- [amqplib](https://github.com/amqp-node/amqplib) - AMQP 0-9-1 клиент для RabbitMQ
- [Nodemailer](https://github.com/nodemailer/nodemailer) - Отправка email-сообщений
- [@nestjs-modules/mailer](https://github.com/nest-modules/mailer) - Модуль NestJS для отправки писем
- [Argon2](https://github.com/ranisalt/node-argon2) - Хэширование паролей
- [@nestjs/jwt](https://github.com/nestjs/jwt) - JWT-модуль для NestJS
- [@nestjs/passport](https://github.com/nestjs/passport) - Passport-модуль для NestJS
- [Passport](https://github.com/jaredhanson/passport) - Стратегии аутентификации
- [passport-jwt](https://github.com/mikenicholson/passport-jwt) - JWT-стратегия для Passport
- [class-validator](https://github.com/typestack/class-validator) - Валидация DTO
- [class-transformer](https://github.com/typestack/class-transformer) - Трансформация объектов
- [uuid](https://github.com/uuidjs/uuid) - Генерация уникальных идентификаторов
- [slugify](https://github.com/simov/slugify) - Генерация URL-дружественных слаг-строк
- [@nestjs/config](https://github.com/nestjs/config) - Управление конфигурацией через переменные окружения
- [@nestjs/throttler](https://github.com/nestjs/throttler) - Лимитирование запросов
- [@nestjs/terminus](https://github.com/nestjs/terminus) - Health checks / мониторинг состояния сервисов
- [@nestjs/schedule](https://github.com/nestjs/schedule) - Планировщик задач (cron jobs)
- [@nestjs/microservices](https://github.com/nestjs/microservices) - Нативная поддержка микросервисной архитектуры
- [@nestjs/platform-express](https://github.com/nestjs/platform-express) - Express-адаптер для NestJS
- [@nestjs-modules/ioredis](https://github.com/nestjs-modules/ioredis) - Redis-модуль для NestJS
- [nestjs-pino](https://github.com/iamolegga/nestjs-pino) - Логирование через Pino
- [pino-http](https://github.com/pinojs/pino-http) - HTTP-логирование для Pino
- [pino-pretty](https://github.com/pinojs/pino-pretty) - Красивое форматирование логов
- [ua-parser-js](https://github.com/faisalman/ua-parser-js) - Парсинг User-Agent строк
- [cookie-parser](https://github.com/expressjs/cookie-parser) - Парсинг кук
- [csurf](https://github.com/expressjs/csurf) - CSRF-защита
- [helmet](https://github.com/helmetjs/helmet) - Защита HTTP-заголовков (gateway)
- [compression](https://github.com/expressjs/compression) - Gzip-сжатие ответов (gateway)
- [express-rate-limit](https://github.com/express-rate-limit/express-rate-limit) - Rate limiting для gateway
- [http-proxy-middleware](https://github.com/chimurai/http-proxy-middleware) - Проксирование запросов (gateway)
- [prom-client](https://github.com/siimon/prom-client) - Метрики для Prometheus
- [@willsoto/nestjs-prometheus](https://github.com/willsoto/nestjs-prometheus) - Prometheus-модуль для NestJS

## Infrastructure

- [Docker](https://github.com/docker) - Контейнеризация всех сервисов
- [Grafana](https://github.com/grafana/grafana) - Визуализация метрик и логов
- [Prometheus](https://github.com/prometheus/prometheus) - Сбор метрик с сервисов
- [Loki](https://github.com/grafana/loki) - Агрегация и хранение логов
- [Promtail](https://github.com/grafana/loki/tree/main/clients/cmd/promtail) - Сбор логов и отправка в Loki
