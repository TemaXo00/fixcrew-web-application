# Структура API

```text
.
├── blog-service         # Сервис блога
├── file-service         # Сервис файлов
├── gateway-service      # Точка входа в backend
├── info-service         # Сервис информации
├── mail-service         # Сервис почты
├── order-service        # Сервис заказов
└── user-service         # Сервис пользователей
```

Для получения доступа к сервисам блога, файлов, информации, заказов, пользователей используется Gateway. Он использует http-proxy-middleware и маршрутизирует трафик по следующим маршрутам:

```text
/blog -> blog-service
/file -> file-service
/info -> info-service
/order -> order-service
/user -> user-service
```

Дальше маршруты для отдельных сервисов будут рассматриваться от их корня. Чтобы получить доступ из полноценного приложения, следует добавлять в начале эти пути

# Сервисы

## Blog Service

Сервис для хранения информации о блоге. Включает в себя управление статьями, работу с тегами

### База данных

```text
# Статья
id              # ID статьи
name            # Название
slug            # Slug (пример: Починка холодильника -> починка-холодильника) для сайта
cover_id        # ID обложки
short_desc      # Краткое описание
content         # Содержимое статьи (Markdown)
status          # Статус (выложена, черновик, в архиве)
tags            # Теги (связь многие-ко-многим)
created_at      # Время создания
updated_at      # Время обновления

# Тег
id              # ID тега
name            # Название
articles        # Статьи (связь многие-ко-многим)
created_at      # Дата создания
updated_at      # Дата обновления
```

## File Service

Сервис для хранения файлов. Интегрирован с MinIO, чтобы отправлять туда файлы. Имеет базу данных для возможности получать по ID необходимый файл

### Маршруты

```text
# Files Module
POST /upload              # Добавление файла. Требует файл, название bucket, видимость
GET /public/:id           # Получение публичного файла
GET /private/:id          # Получение приватного файла
DELETE /:id               # Удаление файла
```

### База данных

```text
# Файл
id             # ID файла
filename       # Название
extension      # Расширение
mimeType       # Тип MIME
size           # Размер
bucket         # Ведро (сервис, к которому относится файл)
key            # Ключ (в MinIO)
visibility     # Видимость (приватный или публичный)
created_at     # Дата создания
```
