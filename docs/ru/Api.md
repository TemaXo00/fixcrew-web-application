# Структура API

```text
.
├── blog-service         # Сервис блога
├── file-service         # Сервис файлов
├── gateway-service      # Точка входа в backend
├── info-service         # Сервис информации
├── mail-service         # Сервис почты
├── order-service        # Сервис заказов
└── user-service         # Сервис пользователей
```

Для получения доступа к сервисам блога, файлов, информации, заказов, пользователей используется Gateway. Он использует http-proxy-middleware и маршрутизирует трафик по следующим маршрутам:

```text
/blog -> blog-service
/file -> file-service
/info -> info-service
/order -> order-service
/user -> user-service
```

Дальше маршруты для отдельных сервисов будут рассматриваться от их корня. Чтобы получить доступ из полноценного приложения, следует добавлять в начале эти пути. Пример:

```bash
# Получение информации о регионах (Info Service)
curl http://localhost:3000/info/regions
```

# Сервисы

## Blog Service

Сервис для хранения информации о блоге. Включает в себя управление статьями, работу с тегами

### База данных

```text
# Статья
id              # ID статьи
name            # Название
slug            # Slug (пример: Починка холодильника за 5 минут -> починка-холодильника-за-5-минут) для сайта
cover_id        # ID обложки
short_desc      # Краткое описание
content         # Содержимое статьи (Markdown)
status          # Статус (выложена, черновик, в архиве)
tags            # Теги (связь многие-ко-многим)
created_at      # Время создания
updated_at      # Время обновления

# Тег
id              # ID тега
name            # Название
articles        # Статьи (связь многие-ко-многим)
created_at      # Дата создания
updated_at      # Дата обновления
```

## File Service

Сервис для хранения файлов. Интегрирован с MinIO, чтобы отправлять туда файлы. Имеет базу данных для возможности получать по ID необходимый файл

### Маршруты

```text
# Файлы
POST /upload              # Добавление файла. Требует файл, название bucket, видимость
GET /public/:id           # Получение публичного файла
GET /private/:id          # Получение приватного файла
DELETE /:id               # Удаление файла
```

### База данных

```text
# Файл
id             # ID файла
filename       # Название
extension      # Расширение
mimeType       # Тип MIME
size           # Размер
bucket         # Ведро (сервис, к которому относится файл)
key            # Ключ (в MinIO)
visibility     # Видимость (приватный или публичный)
created_at     # Дата создания
```

## Info Service

Сервис для получения основной информации. Содержит информацию о возможных услугах и регионах 

### Маршруты

```text
# Категории
GET /categories                            # Получение категорий. Поддерживает Query-параметр type_id для поиска по типу
POST /categories                           # Создание категории
PUT /categories/:id/type                   # Изменение типа категории
PATCH /categories/:id/name                 # Изменение имени категории
DELETE /categories/:id                     # Удаление категории

# Регионы
GET /regions                               # Получение информации о регионах
POST /regions                              # Создание региона
PATCH /regions/:id                         # Изменение региона
DELETE /regions/:id                        # Удаление региона

# Услуги
GET /services                              # Получение всех услуг с пагинацией
GET /services/active                       # Получение активных услуг
GET /services/:slug                        # Детальная информация о услуге по Slug
POST /services                             # Создание услуги
PATCH /services/:id/price                  # Изменение цены
PATCH /services/:id/name                   # Изменение названия
PATCH /services/:id/description            # Изменение описания
PATCH /services/:id/sale-percent           # Изменение скидки
PATCH /services/:id/cover                  # Изменение обложки
PATCH /services/:id/category               # Изменение категории
PATCH /services/:id/toggle                 # Включение/отключение услуги
DELETE /services/:id                       # Удаление услуги

# Типы
GET /types                                 # Получение типа
POST /types                                # Создание типа
PUT /types/:id                             # Обновление типа
DELETE /types/:id                          # Удаление типа
```

### База данных

```text
# Регион
id                       # ID региона
name                     # Название
avg_response             # Среднее время ответа (в минутах)
is_active                # Статус активности
created_at               # Время создания
updated_at               # Время изменения

# Тип
id                       # ID типа
name                     # Название
categories               # Категории (связь один-ко-многим)
created_at               # Время создания
updated_at               # Время изменения

# Категория
id                       # ID категории
name                     # Название
type_id                  # ID привязанного типа
services                 # Услуги (связь один-ко-многим)
created_at               # Время создания
updated_at               # Время изменения

# Услуга
id                       # ID услуги
name                     # Название услуги
slug                     # Slug (пример: Диагностика-неисправности -> диагностика-неисправности)
description              # Описание (Markdown)
cover_id                 # ID обложки
price                    # Цена
sale_percent             # Процент скидки
avg_time                 # Среднее время выполнения
is_active                # Статус активности
category_id              # ID категории
created_at               # Время создания
updated_at               # Время изменения
```
